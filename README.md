# Infinity2Indesign
Convert CSV files from Infinity to idml for Indesign
The Infinity2Indesign utility provides a zero-loss text synchronization workflow between Affinity Publisher on Windows 11 and Adobe InDesign on macOS using surgical XML injection. By placing core files (conversor.py, Convertir.bat, and plantilla.idml) in a local Windows workspace, users can edit text in Affinity and convert the exported SVG back into a clean, fully intact IDML file. The process preserves original layouts, frames, and layers while preventing crashes and formatting loss during cross-platform hand-offs.
